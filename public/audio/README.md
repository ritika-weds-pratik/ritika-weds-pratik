# Ambient music

Place your royalty-free shehnai / instrumental track here as:

```
ambient.mp3
```

The site's `AudioProvider` loops `/audio/ambient.mp3` softly (35% volume)
and unlocks it on the guest's first interaction — the wax-seal tap in the
entry experience. A persistent mute/unmute control lives in the navbar.

If `ambient.mp3` is absent, the player silently no-ops (no error shown to
guests). Swap the file at any time — no code change required.

Suggested sources for royalty-free Indian instrumental music:
- Pixabay Music (free, no attribution): https://pixabay.com/music/search/shehnai/
- YouTube Audio Library
- Bensound

Recommended: a calm, instrumental track under 4 minutes that loops cleanly.
